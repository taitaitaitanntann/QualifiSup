# QualifiSup 完成版ベース

本パッケージは、QualifiSupを本格運用へ進めるためのNext.js + Supabase構成です。

## 含まれるもの
- ホーム
- 資格検索
- 資格詳細
- 資格者検索
- 質問広場
- 相談画面
- ログイン画面
- Supabase用データベーススキーマ
- 公式情報の確認状態を保存する設計
- 年度別試験スケジュール
- 通報・修正申請・資格掲載申請・同意履歴

## 起動
1. Node.jsをインストール
2. `npm install`
3. `.env.example` を `.env.local` にコピー
4. Supabaseプロジェクトを作成しURL/anon keyを設定
5. Supabase SQL Editorで `supabase/schema.sql` を実行
6. `npm run dev`

## 重要
資格情報はデモ用の表示であり、本番データとして扱わないでください。
本番では各資格の公式実施機関を一次情報として確認し、確認日・出典URL・年度を保存してから公開します。
RLS（Row Level Security）、メール認証、パスワードリセット、管理者権限、画像ストレージ、通報対応、未成年者向け安全設計、規約・プライバシーポリシーの最終確認は本番公開前に実装・確認が必要です。


## STEP 5 完了範囲
- 新規登録画面
- 15歳以上の年齢確認（生年月日入力）
- Supabase Authによるメール/パスワード登録
- メール認証に対応できる構成
- ログイン/ログアウト
- パスワード再設定メール
- 基本プロフィール作成
- 利用規約・プライバシーポリシーへの同意UI
- アカウント画面

### 本番で必ず設定すること
Supabase Dashboardでメール認証、Redirect URL、RLS、Authのメール設定を確認してください。
未成年者向けの同意・安全設計は、実際の運用形態と法的要件に合わせて公開前に最終確認してください。


## STEP 6 完了範囲
- 資格名キーワード検索
- 分野、資格種類、受験資格、実技試験、受験料上限、並び順フィルター
- Supabaseに接続できた場合は `verification_status='verified'` の資格をDBから取得
- DB未接続時は公式確認済み初期データを表示
- `supabase/seed_qualifications.sql` を実行すると初期資格データを登録可能
- 未確認資格は検索結果に出さない設計
STEP 7 - 資格者検索
- 資格者をキーワード・状況・分野・勉強方法・相談内容・1日勉強時間で絞り込み
- おすすめ順は条件一致→役に立った割合→相談件数
- Supabase接続時は profiles / user_qualifications / consultations / consultation_ratings から表示
- 資格者プロフィール画面を追加
- 未接続時はデモデータを表示
